# Domain primer: power transformers

> Extracted from PROJECT_SPEC.md §4. Read this before touching agent or classification code.

## Why power transformers matter right now (2024–2026)

- Lead times: ~50 weeks pre-2020 → **100+ weeks** today for large units (100 MVA+).
- Demand drivers: hyperscale datacenter buildout (AI/cloud), IRA grid modernization (US), REPowerEU grid upgrades (EU), EV charging, renewable integration.
- Supply constraints: limited qualified manufacturers globally, GOES bottleneck, skilled labour shortage.

## Key logistics corridors

- Korea → US East Coast
- Korea → EU North Sea (Antwerp, Rotterdam, Bremerhaven)
- Japan → US

Heavy-lift vessel capacity is itself a bottleneck.

## Contract clauses unique to this commodity

| Clause | Description |
|---|---|
| GOES indexation | Escalators tied to published steel indices |
| Cu/Al indexation | Pass-through at agreed LME averages over a defined window |
| Force majeure | Typhoon/earthquake carve-outs for Korean/Japanese suppliers |
| Heavy-lift shipping | Who bears risk and cost of vessel availability |
| Delivery slot guarantees | Slot reservations are contractual assets at 100+ week backlog |
| Liquidated damages | Late delivery penalties |
| Incoterms | Delivery basis (DAP, CIF, FOB) and named place |
